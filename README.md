# 📊 Digital Marketing Analytics Dashboard

Analyzed 10,000+ rows of web traffic and campaign data to surface actionable insights across 7 marketing channels.

**Tools:** Python · Pandas · Plotly

---

## 📁 Files
| File | Description |
|------|-------------|
| `analysis.py` | Full data cleaning, aggregation, and insight generation |
| `marketing_data.csv` | 10,000-row simulated campaign dataset |
| `dashboard.html` | Interactive 6-panel Plotly dashboard |

---

## 🔍 Key Insights
- **Google Ads** drove the highest traffic (360K+ sessions) but Email outperformed it on conversion rate
- **Email campaigns** achieved the best conversion rate at **7.75%** across all channels
- **Instagram** had the highest bounce rate (65.2%), flagging a landing page optimisation opportunity
- **Google Ads** delivered the best ROAS at **214x** among paid channels
